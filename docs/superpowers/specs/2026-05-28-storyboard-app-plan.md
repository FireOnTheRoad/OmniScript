# Storyboard App — 实施计划

## 总览

按照"搭骨架 → 通数据 → 建视图 → 装配件 → 打磨优化"的顺序，分 5 个阶段逐步交付。

---

## 阶段 1：项目脚手架 & Electron 基础

**目标**：可以跑起来的空 Electron + Vue 3 桌面应用。

### 任务

| # | 任务 | 预计产出 |
|---|------|----------|
| 1.1 | 用 `electron-vite` 初始化项目，配置 Vue 3 + TypeScript | 基础项目骨架 |
| 1.2 | 配置 Electron 主进程窗口（尺寸、标题、菜单） | 能打开的桌面窗口 |
| 1.3 | 配置 IPC 通信桥（preload.ts + channel 定义） | 渲染进程可安全调用主进程 |
| 1.4 | 安装 Naive UI + Pinia + Vue Router，配置基础布局（Header + 路由 + StatusBar） | 空壳界面可见 |
| 1.5 | 配置 TypeScript 路径别名、ESLint、Prettier | 开发体验完善 |

**验收标准**：桌面窗口打开，看到顶部标题栏 + 底部状态栏 + 空白工作区，三个 Tab 点击切换显示不同的空白视图。

---

## 阶段 2：数据层 & 文件 I/O

**目标**：项目文件的打开、解析、保存、监听全部打通。

### 任务

| # | 任务 | 预计产出 |
|---|------|----------|
| 2.1 | 定义 TypeScript 类型（Project, Shot, SketchObject, ScriptRef 等） | `src/types/index.ts` |
| 2.2 | 实现主进程 IPC Handler：项目打开（读 project.json + storyboard.json + script.md） | 文件 → 内存 |
| 2.3 | 实现主进程 IPC Handler：项目保存（写回三个文件，debounce） | 内存 → 文件 |
| 2.4 | 实现主进程文件监听（chokidar 监控项目目录，IPC 通知渲染进程） | 外部修改感知 |
| 2.5 | 实现 Pinia projectStore（加载、保存、监听重载、冲突检测） | 全局状态就绪 |
| 2.6 | 实现 useProject / useIpc composables | 组件层 API |

**验收标准**：菜单打开一个 `.storyboard` 文件夹 → 数据进入 Store → 修改后自动保存 → 用外部编辑器改 JSON → 应用自动刷新。

---

## 阶段 3：三大核心视图

**目标**：三个主要工作视图实现完整，可以完成从剧本到分镜的完整流程。

### 3.1 剧本编辑视图（ScriptView）

| # | 任务 | 产出 |
|---|------|------|
| 3.1.1 | 集成 Milkdown Markdown 编辑器，加载 script.md | 可编辑的剧本编辑器 |
| 3.1.2 | 实现段落解析（按空行/标题分割）与段落选中交互 | 段落可选中、高亮 |
| 3.1.3 | 实现右栏"关联分镜卡片"列表（根据 scriptRef 过滤显示） | 选段落 → 看关联镜头 |
| 3.1.4 | 实现"手动添加镜头"按钮（选段落 → 创建空白 Shot） | 手动模式 |
| 3.1.5 | 实现"智能拆解"对话框（选范围 → 批量生成空白 Shot） | 智能模式 |

### 3.2 分镜表视图（StoryboardView）

| # | 任务 | 产出 |
|---|------|------|
| 3.2.1 | 基于 Naive UI DataTable 实现分镜表格（全部列、行内编辑） | 表格模式 |
| 3.2.2 | 实现拖拽排序（镜号自动重排） | 排序功能 |
| 3.2.3 | 实现筛选/搜索（按景别、运镜过滤） | 筛选功能 |
| 3.2.4 | 实现卡片画廊模式（ShotCardGrid + ShotCard） | 卡片模式 |
| 3.2.5 | 实现表格/画廊模式切换 | 模式切换 |

### 3.3 镜头绘图视图（ShotEditView）

| # | 任务 | 产出 |
|---|------|------|
| 3.3.1 | 集成 Fabric.js Canvas，实现基本绘图工具（画笔、矩形、圆形、箭头、文字） | 草图绘制 |
| 3.3.2 | 实现绘图工具栏（画笔粗细、颜色选择、撤销/重做） | 工具栏 |
| 3.3.3 | 实现参考图加载 + 标注叠加层（文字标签、箭头标注） | 参考图标注 |
| 3.3.4 | 实现右侧属性面板（景别、运镜、时长、对白、转场、描述、备注编辑） | 属性编辑 |
| 3.3.5 | 实现草图数据序列化/反序列化（Canvas 对象 ↔ sketch JSON） | 数据持久化 |

**验收标准**：完整的剧本→分镜流程走通——写剧本 → 智能拆解生成镜头 → 在分镜表编辑字段 → 进入绘图视图画草图和标注 → 所有数据正确保存和加载。

## 阶段 4：导出 & 协作功能

**目标**：PDF/Excel 导出可用，坚果云协作流程完整。

### 任务

| # | 任务 | 产出 |
|---|------|------|
| 4.1 | 实现 PDF 导出（A4 分镜表排版，含表头、镜头行、草图缩略图、分页） | PDF 导出 |
| 4.2 | 实现 Excel 导出（ExcelJS，带样式、列宽自适应） | Excel 导出 |
| 4.3 | 实现导出对话框（预览、选择导出范围、模板选择） | 导出 UI |
| 4.4 | 实现编辑冲突检测（保存前检查 mtime + 冲突提示弹窗） | 冲突保护 |
| 4.5 | 文件 → 新建项目、文件 → 最近打开列表 | 项目管理 |

**验收标准**：导出按钮生成可打印的 PDF 和可打开的 xlsx；坚果云同步时外部修改触发自动刷新，冲突时弹窗提示。

## 依赖关系

```
阶段 1 ──→ 阶段 2 ──→ 阶段 3.1 ──→ 阶段 3.2 ──→ 阶段 3.3
                              ↘             ↘           ↘
                               阶段 4 ←──── 阶段 4 ←──── 阶段 4
                                                ↓
                                            阶段 5
```

- 阶段 3 的三个视图可以并行开发（3.1 → 3.2 → 3.3 依次推进也可）
- 阶段 4 依赖 3.2 的表格数据和 3.3 的草图数据
- 阶段 5 必须在所有功能完成后进行

## 风险点

| 风险 | 应对 |
|------|------|
| Milkdown 段落解析不够灵活 | 备选：直接用 textarea + 自定义段落解析，放弃所见即所得 |
| Fabric.js 草图序列化复杂 | 先用简化版本（只支持笔刷和矩形），后续扩展 |
| Electron 打包体积大 | 初期可接受，后续考虑用 asar 压缩 + 按需加载 |
| Windows/macOS 文件路径差异 | 统一用 `path` 模块处理，Node.js 原生支持 |
